## Gramática da linha (6 campos, separador ` | `)

```
DATA | TIPO | ALVO | VER | REF | TEXTO
```

| Campo | Regra |
|---|---|
| `DATA` | `AAAA-MM-DD` |
| `TIPO` | uma palavra da tabela abaixo, MAIÚSCULA |
| `ALVO` | tela, lista, fluxo ou módulo (`scr_Cobertura_1`, `ficha_producao`, `App.Formulas`). `—` se não se aplica |
| `VER` | versão do alvo (`v0.2.0`). `—` se não se aplica |
| `REF` | IDs separados por espaço: `MEL-083 C39 B§3.12`. `—` se não se aplica |
| `TEXTO` | uma frase. Metadados em tags no fim: `#F0 #esfM #impA #dep:MEL-012` |

## Tipos

| TIPO | Quando usar | Efeito no estado |
|---|---|---|
| `ABERTO` | melhoria nasce | item entra no backlog |
| `ENTREGUE` | YAML/fórmula pronta, ainda não publicada | item sai do backlog, entra em "aguardando publish" |
| `PUBLICADO` | publicado no app | item vira "em produção" |
| `VALIDADO` | conferido contra CSV/produção | item fecha |
| `FEITO` | atalho: nasceu e morreu no mesmo ciclo | item fecha |
| `BLOQUEADO` | travado por insumo externo | item sai da fila ativa |
| `RESOLVIDO` | destrava um `BLOQUEADO` ou `PENDÊNCIA` anterior | item volta pra fila |
| `PENDÊNCIA` | pergunta/insumo que falta (ex-P9) | entra na lista de pendências |
| `LIÇÃO` | erro pago, para não repetir | vira candidata a norma |
| `NORMA` | regra nova, **vale a partir da linha** | Mestre absorve na próxima consolidação |
| `DECISÃO` | escolha arquitetural registrada | — |
| `REVERTIDO` | desfez uma entrega | item reabre |
| `DESCARTADO` | não vai ser feito | item fecha sem execução |

## As 5 regras

1. **Nunca edite uma linha passada.** Mudou o status? Nova linha citando o mesmo `REF`.
2. **Uma linha = um fato.** Se são dois fatos, são duas linhas.
3. **ID novo:** rode `python3 gms.py --novo`. Nunca reusar ID.
4. **`NORMA` é vinculante na hora em que é escrita** — não espera o Mestre. O Mestre absorve depois, em lote (`python3 gms.py --consolidar`).
5. **Citado em conversa e não escrito aqui não existe.** Lição paga na v1.5.
